## 🚀 Features

- 📅 **Date Range Selection**
- 🌍 **Dynamic Multi-Level Filters**
  - Region
  - State (updates based on selected region)
  - City (updates based on selected state)
- 📈 **Key Performance Indicators (KPIs)**
  - Total Sales
  - Total Profit
  - Total Orders
- 📊 **Interactive Visualizations**
  - Category-wise Sales (Bar Chart)
  - Region-wise Sales (Donut Chart)
  - Profit vs Sales (Scatter Plot)
  - Segment-wise Sales (Funnel Chart)
  - Category & Segment Profit (Sunburst Chart)
  - Ship Mode vs Sales (Horizontal Bar Chart)
  - Hierarchical Sales View (Treemap)

## ▶️ How to Run Locally

1️⃣ Clone the repository
```bash
git clone https://github.com/mrunmayee3108/Sales-Analysis-Dashboard.git
cd Sales-Analysis-Dashboard
````

2️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

3️⃣ Run the Streamlit app

```bash
streamlit run dashboard.py
```
